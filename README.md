## Final Capability Target

By the end of Day 120, you should be able to:

1. Understand computer networking from packets to enterprise architecture.
2. Analyze TCP/IP traffic with Wireshark.
3. Discover and inventory network services.
4. Secure Linux and Windows systems.
5. Understand Windows internals and Active Directory security.
6. Configure and analyze host/network firewalls.
7. Understand practical cryptography and PKI.
8. Design IAM and Zero Trust controls.
9. Build a small SOC environment.
10. Collect and normalize security telemetry.
11. Operate a SIEM.
12. Perform alert triage.
13. Investigate IOCs.
14. Use threat intelligence effectively.
15. Map activity to MITRE ATT&CK.
16. Write detection rules using Sigma concepts.
17. Monitor networks using Zeek and Suricata.
18. Perform threat hunting.
19. Conduct incident response.
20. Perform basic disk and memory forensics.
21. Understand malware analysis workflows.
22. Monitor cloud environments.
23. Secure containers and Kubernetes.
24. Automate security workflows with Python.
25. Design SOAR-style response playbooks.
26. Conduct purple-team detection validation.
27. Build an end-to-end SOC laboratory.
28. Investigate a simulated enterprise compromise.
29. Produce technical incident reports.
30. Communicate security findings to technical and executive audiences.
